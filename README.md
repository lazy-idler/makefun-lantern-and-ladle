**Lantern & Ladle** is an original offline HTML5 Canvas midnight izakaya & wok bistro cooking game built for make.fun's *Make the best cooking game* bounty. Chop fresh proteins and greens, simmer rich miso broth and noodles in the copper kettle, toss sizzling shrimp and chashu in the ember wok for Wok Hei bonuses, layer multi-ingredient bowls on the assembly board, and ring the brass service bell across escalating rush shifts with kitchen upgrades and procedural Web Audio SFX.

## Run it

```sh
node serve.ts
```

Open `http://localhost:8080` in a desktop browser and play with mouse or keyboard (`1-8` pantry, `C` chop, `B` kettle, `F` wok toss, `Space` assemble, `Enter` serve, `X` sink, `H` menu, `M` mute, `P` pause).
